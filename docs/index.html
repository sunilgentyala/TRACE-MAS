Abstract

Modern AI systems rarely rely on a single model. A coder agent drafts a module, a quality-assurance agent reviews it, and a deployment agent ships it. Three distinct LLMs. One shared pipeline. Zero cryptographic cross-verification between them. When that pipeline is attacked, the consequences are not isolated to one model. They propagate invisibly across the entire chain.

This paper identifies four structurally related failure modes that define the attack surface of such pipelines: cascading alignment drift, inter-agent identity spoofing, cross-agent prompt injection, and temporal adversarial manipulation. To address all four jointly, we introduce TRACE-MAS, a unified theoretical framework grounded in contraction theory, zero-knowledge cryptography, and statistical change detection.

TRACE-MAS delivers three provable guarantees: a chain-length-independent drift envelope, a logarithmically-tight spoofing-and-injection acceptance bound, and a sub-Gaussian temporal miss probability. Their composition yields a single composite failure bound whose three terms are independently controllable by parameter choice.

A small attack at step 1 becomes a large effect at step 3 with no agent detecting it individually.

Temporal Adversarial Attacks
Staged perturbations each below any agent's detection threshold cumulatively drive the system to a malicious end-state.

Mathematical Framework

TRACE-MAS models the inter-agent surface as the tuple S = ({h_i}, {π_i}, M, ξ) where h_i are agent outputs, π_i are cryptographic attestations, M is joint memory, and ξ is the verifier reference signal. Three theorems protect three components.

Theorem 1 — Drift-Decay under Contractive Aggregation

Verifier-mediated aggregation αi+1 = (1−γ)âi+1 + γξi produces a contractive recursion whose asymptotic drift envelope is:

δ∞ ≤ ρ + λε / (1 − λ)   [independent of chain length n]

Theorem 2 — Spoofing-and-Injection Acceptance Bound

Dynamic ZKP threshold τi(t) = τ0 + κ·log(1+ρi(t)) bounds rogue acceptance per round:

Pr[rogue accepted] ≤ 2⁻ˢ + e⁻τ/μ

Prompt injection is caught here: an injected message violates the policy commitment Cθ, so no valid proof π can be generated for it.

Theorem 3 — Temporal Detection Bound

Sliding-window KL functional I(t, Tw) over joint memory M detects slow attacks:

Pr[undetected] ≤ exp( −Tw·(φ(B)−ν)² / 2σ² )

Composite Security Envelope

Pₖₐₖₗ ≤ 1[δ∞ > δ*] + T(2⁻ˢ + ε) + T·exp(−Tw*·(φ(B)−ν)²/2σ²)

Each term is independently controllable. Drift cannot inflate the spoofing or temporal terms.

Algorithm

The TRACE-MAS unified runtime processes each round in three sequential phases:

TRACE-MAS(agents={A1..An}, verifiers=V, intent=α0, ZKP, params):
  Initialize: M ← ∅

  for t = 1 to T:
    for each agent Ai acting at round t:

      ── Phase 1: Attestation Gate ────────────────────────────
      â, m  ← Ai produces output and message
      π     ← Prove(sk_i, m, policy_commit_i, history_i)
      ρ     ← compute_risk_score(Ai)
      τ     ← τ0 + κ·log(1 + ρ)
      if Verify(π) ≠ 1 or behavioral_score(π, history) < τ:
        → HALT: SpoofOrInjectAlarm  [catches spoofing + prompt injection]

      ── Phase 2: Drift Correction ────────────────────────────
      ξ     ← verifier quorum V produces reference signal
      γ     ← max(γ_min, g(ρ))
      α_next ← (1-γ)·â + γ·ξ         [contractive aggregation]
      if ‖α_next - α0‖ > δ*:
        → HALT: DriftAlarm
      M ← M ∪ {α_next}

    ── Phase 3: Temporal Monitoring ─────────────────────────
    I ← sup KL(M^s1 ‖ M^s2) over window Tw*
    if I > φ(B):
      → HALT: TemporalAlarm; rollback to last certified checkpoint

  return certified trajectory (α1, …, αn)

Per-round complexity: O(log|A|) ZKP verification + O(d) aggregation + O(Tw*) temporal functional.
